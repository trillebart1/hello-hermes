# hello-hermes

Basit bir Node.js + Express “Merhaba Dünya” uygulaması.

## Yerelde çalıştırma

```bash
npm install
npm start
```

Varsayılan adres: <http://localhost:3000>

## Ortam değişkenleri

- `PORT`: Uygulamanın dinleyeceği port. Varsayılan: `3000`.

## Sağlık kontrolü

```bash
curl http://localhost:3000/health
```
